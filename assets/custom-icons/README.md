# 🎨 Ikony z Aseprite (Custom Pixel Art Icons)

Tutaj możesz wrzucić własne ikony narysowane w **Aseprite** (lub dowolnym edytorze grafiki pikselowej).

### 📐 Rekomendowane wymiary:
- Format: **PNG z przezroczystością**
- Rozmiar: **16x16 px** lub **24x24 px** (odtwarzacz automatycznie je wyskaluje w technologii `image-rendering: pixelated;`)

### 🏷 Nazwy plików:
Gdy zapiszesz plik w tym folderze pod poniższą nazwą, odtwarzacz automatycznie go wykryje i podmieni:

| Plik | Zastosowanie |
| :--- | :--- |
| `play.png` | Przycisk Odtwarzaj (Play) |
| `pause.png` | Przycisk Pauza (Pause) |
| `prev.png` | Poprzedni utwór |
| `next.png` | Następny utwór |
| `volume.png` | Ikona głośnika |
| `mute.png` | Ikona wyciszenia |
| `shuffle.png` | Losowe odtwarzanie (Shuffle) |
| `repeat.png` | Pętla (Repeat) |
| `fav.png` | Polubienie utworu (Ulubione / Gwiazdka / Diament) |
| `add.png` | Dodawanie do playlisty |
| `folder.png` | Otwieranie folderu |
| `omi.png` | Portret / emblemat Omi (Snake Nation) |

### 🎨 Sugerowana paleta Omi (Edgerunners 2):
- **Zielony wilczy (włosy):** `#00FF88` lub `#10B981`
- **Fiolet Snake Nation (tatuaż):** `#B026FF` lub `#9333EA`
- **Różowy neon (uprząż):** `#FF2A85`
- **Błękit kobaltowy (kamizelka/oczy):** `#0088FF` lub `#00E5FF`
- **Żółty akcent (buty/kontrast):** `#FCEE0A`
- **Stalowy chrom (Gorilla Arms):** `#8EA0B5`
